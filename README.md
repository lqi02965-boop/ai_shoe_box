# 基于 K230 与 STM32 的人脸识别智能鞋柜系统

> **K230（边缘人脸识别）+ STM32F407ZE（柜门控制）+ PC 上位机（数据管理）** 三端协同的自助存取系统：存鞋时人脸绑定身份自动开柜，取鞋时人脸验证自动开门，支持临时人脸录入即用即删。

## 系统架构

```
K230 视觉终端 ──串口自定义帧协议──> STM32F407ZE 主控 <──串口──> PC 上位机(PySide6 + SQLite)
     │                                  │
  人脸检测/特征比对              舵机柜门 / RGB 状态灯 / 矩阵键盘 / OLED
```

## 功能特性

- **端侧人脸识别**：基于 K230 官方人脸识别示例二次开发，注册阶段提取特征存为本地文件，识别阶段余弦相似度匹配，无需依赖 PC 算力
- **三端通信协议**：自定义串口帧（帧头/长度/命令/CRC 校验）+ 接收状态机 + ORE 溢出保护，保证指令可靠传输
- **STM32 多外设协同**：独立编写 IIC/SPI/串口驱动与 GPIO 定义；SG90 舵机控制柜门；RGB LED 四色状态指示（绿空闲/红待洗/黄洗中/蓝已洗）；4×4 矩阵键盘密码取鞋；OLED 软件 I2C 局部刷新
- **非阻塞状态机**：100ms tick 状态机替代阻塞延时，键盘扫描/串口解析/舵机控制并行不互阻；舵机位置跟踪 + 死区过滤消除抖动
- **PC 上位机**：PySide6 管理界面，SQLite3 存储用户档案与存取记录，支持临时人脸录入（取鞋即删）与远程开锁

## 技术栈

C（STM32 标准外设库）· MicroPython（CanMV）· PySide6 · SQLite3 · 串口自定义帧协议

## 目录结构

```
├── 32mode/           # STM32 端 Keil 工程（含 CRC8 + 接收状态机的可靠协议实现）
├── main.py           # PC 端 / 协议辅助脚本
└── uart_protocol.py  # 串口协议实现
```
